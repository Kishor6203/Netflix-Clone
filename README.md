# 🎬 Netflix Clone

A responsive Netflix Clone built using modern web technologies. This project recreates the Netflix user interface, 
allowing users to browse movies, view details, and enjoy a smooth streaming platform experience.

---

## 🚀 Features

- 🎥 Netflix-inspired UI
- 📱 Fully responsive design
- 🔍 Browse movies and TV shows
- 🎞️ Movie banners and trailers
- ❤️ Add to favorites
- 🔐 User authentication (Firebase/Auth)
- 🌙 Dark theme
- ⚡ Fast loading and optimized performance

---

## 🛠️ Tech Stack

- HTML5
- Tailwind
- JavaScript (ES6+)
- React.js
- Firebase (Authentication & Hosting)
- TMDB API
- Axios
- React Router
- Context API / Redux

## 🔑 Environment Variables

Create a `.env` file in the root directory and add:

```env
REACT_APP_TMDB_API_KEY=your_tmdb_api_key
REACT_APP_FIREBASE_API_KEY=your_firebase_api_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_auth_domain
REACT_APP_FIREBASE_PROJECT_ID=your_project_id
```
