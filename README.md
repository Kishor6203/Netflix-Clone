# 🎬 Netflix Clone

A responsive Netflix Clone built using modern web technologies. This project recreates the Netflix user interface, 
allowing users to browse movies, view details, and enjoy a smooth streaming platform experience.

---

## 🚀 Features

- 🎥 Netflix-inspired UI
- 📱 Fully responsive design
- 🔍 Browse movies and TV shows
- 🎞️ Movie banners and trailers
- ❤️ Add to favorites
- 🔐 User authentication (Firebase/Auth)
- 🌙 Dark theme
- ⚡ Fast loading and optimized performance

---

## 🛠️ Tech Stack

- HTML5
- Tailwind
- JavaScript (ES6+)
- React.js
- Firebase (Authentication & Hosting)
- TMDB API
- Axios
- React Router
- Context API / Redux

## 🔑 Environment Variables

Create a `.env` file in the root directory and add:

```env

# Firebase
VITE_FIREBASE_API_KEY=YOUR_FIREBASE_API_KEY
VITE_FIREBASE_AUTH_DOMAIN=YOUR_PROJECT.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=YOUR_PROJECT_ID
VITE_FIREBASE_STORAGE_BUCKET=YOUR_PROJECT.firebasestorage.app
VITE_FIREBASE_MESSAGING_SENDER_ID=YOUR_SENDER_ID
VITE_FIREBASE_APP_ID=YOUR_APP_ID
```
